# GastoGuard

**Track. Plan. Save. Grow.**

GastoGuard is a student-focused, offline-friendly expense tracking application designed to help students manage their finances and develop better spending habits.

The application allows users to record their income and expenses, monitor their spending, review transaction history, and understand their spending patterns through organized summaries.

## Project Overview

Managing personal finances can be challenging for students, especially when tracking daily expenses and maintaining a budget. GastoGuard aims to provide a simple and accessible way to monitor financial activities and encourage responsible spending.

The application is being developed using Flutter and Dart, with a focus on a clean, beginner-friendly interface and an offline-friendly experience.

## Current Features

- **Dashboard** – Displays an overview of the user's financial activity.
- **Add Transaction** – Allows users to record income and expenses.
- **Transaction History** – Displays recorded transactions with filtering and organization features.
- **Spending Summary** – Presents spending information through summaries and visual charts.
- **Budget Settings** – Provides weekly and monthly budget limits with configurable spending alerts.
- **Navigation** – Provides navigation between the application's main sections.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK (included with Flutter)
- Visual Studio Code or Android Studio
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Anicakim13/GastoGuard.git
   ```

2. Navigate to the project directory:

   ```bash
   cd GastoGuard
   ```

3. Install the project dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```

### Run on Microsoft Edge

```bash
flutter run -d edge
```

## Testing

Run the following command to execute the project's tests:

```bash
flutter test
```

To check for code issues:

```bash
flutter analyze
```

## Development Status

GastoGuard is currently under active development.

The current implementation includes the main user interface, transaction-related features, spending summaries, and an initial budget settings screen.

**Development notes:**
- Budget settings are currently implemented as a standalone UI feature.
- Transaction data is currently managed in application memory.
- Persistent storage and backend integration have not yet been implemented.
- Additional screens and integrations are planned for future development.
